# DAYZEN - tienda web actualizada

## Publicación en GitHub Pages
1. Descarga y descomprime este ZIP.
2. Abre el repositorio actual de DAYZEN en GitHub.
3. En la pestaña **Code**, entra a la carpeta raíz del repositorio.
4. Sube/reemplaza todos los archivos y carpetas de este ZIP (index.html, styles.css, script.js y assets).
5. Confirma el commit en la rama que ya utiliza GitHub Pages. No cambies la configuración de Pages ni crees otro repositorio.
6. Espera unos minutos y recarga la dirección actual de DAYZEN con Ctrl+F5.

El sitio conserva el flujo de bolsa y pedido por WhatsApp. Los números de WhatsApp configurados en el archivo original se mantienen.

## Dereck 2.0 (gratuito)
- Incluye campo para que el cliente escriba preguntas.
- Respuestas automáticas por palabras clave para promoción, envíos, pagos, disponibilidad y categorías. No utiliza IA externa ni genera cargos por mensaje.
- Promoción automática: con 2 o más unidades, descuenta una sola vez el 10% del artículo de mayor precio.
- El carrito muestra subtotal, descuento y total; el pedido enviado a WhatsApp incluye el cálculo.
- Envíos comunicados por Dereck: Carapungo gratis; Quito $3; resto del Ecuador $6 por Servientrega; Galápagos excluido.
- La web no cobra ni procesa pagos: el equipo confirma el pedido y el pago por WhatsApp.

Nota: Dereck responde con reglas y respuestas preparadas, no es una IA generativa. Si una pregunta no coincide con las reglas, ofrece continuar por WhatsApp.


## Dereck 3.0 - mejoras gratuitas incluidas
- Silueta masculina en la burbuja y en el encabezado del asesor.
- Campo de texto y respuestas por reglas para promociones, envíos, pagos, tallas, disponibilidad y categorías.
- Recomendaciones de regalo por destinatario, categoría y presupuesto cuando esos datos aparecen en la pregunta.
- Recuperación de la bolsa al volver a abrir la tienda desde el mismo navegador y dispositivo (almacenamiento local).
- Registro local de preguntas no reconocidas y acciones del asesor para diagnóstico en ese navegador; el cliente puede enviar la pregunta directamente a WhatsApp.
- La bolsa puede vaciarse manualmente.
- Selector de zona que calcula el envío en el carrito: Carapungo $0, Quito $3, resto del Ecuador $6; bloquea pedidos a Galápagos. El valor y la zona se incluyen en el mensaje de WhatsApp.

## Límites técnicos transparentes
GitHub Pages es alojamiento estático y no incluye una base de datos ni un servidor. Por eso, el historial de bolsa, visitas y preguntas queda únicamente en el navegador del visitante; no se sincroniza contigo ni entre dispositivos. No hay seguimiento central de clientes ni recuperación mediante mensajes automáticos. Para esas funciones se necesitaría un backend o una integración externa, que podría tener límites o costos. Dereck usa reglas programadas, no IA generativa.
