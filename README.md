# DAYZEN — tienda online estática

Sitio web de catálogo y pedidos por WhatsApp, preparado para publicar gratis con GitHub Pages.

## Versión premium (DAYZEN)
- Paleta negra, blanca y dorada, con tipografía editorial.
- Fotografías individuales de zapatos recortadas de las páginas originales del catálogo PDF.
- Las páginas completas originales siguen disponibles en la sección Catálogos.
- Los perfumes se muestran en tarjetas gráficas; el PDF de perfumes recibido contiene nombres y precios, pero no fotografías individuales de frascos.

## Incluye
- Identidad visual DAYZEN y logo proporcionado.
- Catálogo de zapatos con modelos, tallas y precios transcritos del PDF.
- Lista de perfumes y sets con los precios del PDF.
- Páginas originales de los dos catálogos como imágenes para conservar las fotos.
- Búsqueda, filtro, orden por precio y bolsa de compras.
- Botón para enviar el pedido armado a cualquiera de los dos WhatsApp.
- Diseño adaptable a celular y computadora.

## Publicar gratis con GitHub Pages
1. En GitHub crea un repositorio nuevo, por ejemplo `dayzen`.
2. Descomprime este ZIP y sube **todo el contenido interior** (index.html, styles.css, script.js, README.md y carpeta assets) al nivel principal del repositorio.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y carpeta `/ (root)`, luego pulsa **Save**.
6. Espera unos minutos. GitHub mostrará el enlace público de tu página en esa misma sección.

## Importante sobre las compras
La bolsa arma el pedido y abre WhatsApp con el detalle y total estimado. Esta versión usa WhatsApp como único canal de cierre y coordinación de pago, tal como solicitaste. No cobra tarjetas ni procesa pagos dentro de la web.

## Antes de publicar
- Confirma que todos los precios y tallas siguen vigentes.
- El catálogo indica un Adidas VL Court Bold como AGOTADO; se muestra sin botón de agregar.
- En Adidas VL Court 3.0 K aparece una talla US incompleta en el PDF; se conserva la observación en el sitio.
- Revisa si quieres agregar costos de envío, cobertura y métodos de pago.
- Las imágenes de los catálogos se han renderizado desde los PDF para mantener sus fotografías originales.
